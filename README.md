# I AM CONSUL

キーボードを叩くだけで、超絶有能な IT コンサルタントの気分を味わえるブラウザアプリ。
どのキーを叩いても、それらしいスライドが 1 枚ずつ組み上がり、提案書が完成していきます。中身はなくても、体裁は完璧です。

**遊ぶ**: https://www.jumboly.jp/iam-consul/

姉妹作: [FLOWSTATE IDE](https://www.jumboly.jp/best-programmer/)（凄腕プログラマー版）

## ビルド

```sh
node tools/build.mjs   # Node 18 以上
open dist/index.html
```

`tools/build.mjs` は `src/content.js`（デッキと語彙）を検証してから `src/app.html` に埋め込み、次のファイルを生成します。

- `dist/index.html`: そのままブラウザで開ける完成版
- `dist/fragment.html`: claude.ai アーティファクト用（`<html>` などの外枠なし）

検証では、スライドの型ごとの必須項目と、プレースホルダの書式をチェックします。

main ブランチに push すると、GitHub Actions（`.github/workflows/pages.yml`）が同じビルドを実行して GitHub Pages に公開します。

## 操作

| キー | 動作 |
| --- | --- |
| 任意のキー / タップ | スライドを作る（速く叩くほどコンボと時間単価が上がる） |
| F1 | パートナーレビュー（赤ペンが入り、全件反映したら初版に戻る） |
| F2 | 体裁を整える（散らかった図形がピタッと揃う） |
| F3 | 役員プレゼン（スライドショーと拍手） |
| F4 | フレームワーク投入（2×2 マトリクスを次のスライドに割り込ませる） |
| F5 | 緊急案件（20 秒の制限時間つき） |
| F6 | サウンド |
| F7 | 横文字モード（「合意」が「アグリー」になる） |
| Alt + 1〜7 | F キーの代わり |

## コンテンツの書き方

デッキは `src/content.js` に書きます。構成と見せ場の文言は手書きで固定し、数字や社名だけをデッキを開くたびにランダムで埋める方式です。全部をランダムにしないのは、オチの文言が崩れると皮肉が成立しなくなるためです。

| プレースホルダ | 内容 |
| --- | --- |
| `{client}` | クライアント名（デッキごとに 1 社） |
| `{buzz}` | バズワード 1 語 |
| `{n:a-b}` | a〜b の整数 |
| `{n:a-b#name}` | 同じデッキ内で同じ name なら同じ値（見出しとグラフの数字をそろえる） |
| `{pick:x\|y}` | いずれか 1 つ |
| `{fy:+k}` | 今年度から k 年後（`FY27` 形式） |

スライドの型は `cover` `exec` `asis` `matrix` `tree` `message` `gantt` `chart` `org` `cost` `steps` `grid` `pyramid` `appendix` の 14 種類で、必須項目は `tools/build.mjs` の `SCHEMA` にあります。

登場する企業・人物・数字はすべて架空です。メールの差出人アドレスには、予約済みの `.example` ドメインだけを使っています。
